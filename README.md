# 🎵 歌曲世界杯 (Music World Cup)

歌手代表作淘汰赛投票应用，通过"二选一"投票方式，从一位歌手的所有代表作中决出"终极冠军歌曲"。

## 功能特点

- **两种游戏模式**：经典淘汰赛 / 世界杯模式（小组赛+外卡+淘汰赛）
- **歌曲试听**：集成网易云音乐 API，自动定位高潮片段播放
- **键盘操作**：← 选左，→ 选右，Enter 确认，Esc 关闭播放器
- **存档续玩**：支持 localStorage 持久化，随时继续上次的对战

## 支持歌手

| 歌手 | 歌曲数量 |
|------|---------|
| 孙燕姿 | 128 首 |
| 林俊杰 | 64 首 |

## 技术栈

- React 18.3 + Vite 6
- 纯 CSS（无 UI 库）
- localStorage 数据持久化
- HTML5 Audio + 第三方音乐 API

## 游戏规则

### 经典模式
标准单败淘汰赛，128/64 强一路淘汰至冠军，类似网球大满贯对阵。

### 世界杯模式
模仿 FIFA 世界杯赛制：
1. **小组赛**：12 组单循环
2. **外卡复活**：8 个第三名晋级
3. **淘汰赛**：32 → 16 → 8 → 4 → 决赛
